# Original community props

The trusted `catalog-v2.json` owns prop IDs, relative local image paths, source crops, intended sizes, paint order, collision footprints and built-in interactions. An imported package names the catalog revision; it cannot supply resource paths. Crops are `[x,y,width,height]`. Images retain their original RGBA bytes. Both consumers aspect-fit and centre a crop inside the authored placement rectangle. Collision is `[x,y,width,height]` in normalized placement-box fractions, or `null` for a nonblocking floor decoration; it represents fictional furniture feet, never real-building geometry.

The original sixteen props are an unchanged copy of the project's generated campus atlas, with its existing source crops. See [pixel art provenance](../../../docs/assets/PIXEL_ART.md). Eight additional sprites were generated with Codex's built-in image generator on 12 October 2026, from original descriptive prompts, without reference screenshots or third-party sprites. Their prompts are in [community-asset-prompts.json](../../../docs/design/community-asset-prompts.json). No paid AI service is needed to use the bundled images. Generated originals are preserved; runtime crops omit transparent padding and stray faint pixels. Asset hashes are recorded in the catalog. The project distributes this original art under its MIT License, separately from any third-party reference artwork.

The hacker workstation is fictional coding-school decoration, not a record of 42 Belgium's equipment. Arcade, wellness and meeting props are imagined. The secret bookshelf opens one trusted white Construct room, with two burgundy chairs and a CRT: a fictional Easter egg inspired by the user's reference, without film screenshots, actors, dialogue or branded assets. The debugging duck offers a small built-in interaction. Secrets never represent real doors or routes.

Character options are trusted enum values in the catalog. Procedural 32×48 pixel parts use a `[16,44]` foot pivot and four facing directions; imported content selects options, never drawing commands. Real-person portrayals and introductions still need that person's approval before distribution.

## Recognizable founder preset

`avatarPresets.founder-v1` expands the existing original blue-haired founder with white clothing and an orange backpack. The PNG is an unchanged native RGBA generation, referenced to the original project atlas, using Codex's built-in image generator on 12 October. The user's Sea of Stars screenshots are visual direction only; no game pixels or characters are copied. See `docs/design/community-character-prompts.json` for the prompt/reference.

All twenty frames were inspected: front/back/left/right, each idle and four walking poses. Source crops isolate sprites from the nonuniform generated layout rather than assuming a perfect grid. The trusted manifest records source pivots and one uniform source scale. Both consumers rasterize to the same64×96 logical frame, world32×48, footpivot32,88: for output `(x,y)`, sample source-relative `floor((x-footPivot.x)/sourceScale+sourcePivot.x)` and the equivalent y. Outside the crop is transparent; inside, preserve native RGBA bytes. `founder-conformance-v1.json` records exact twenty-frame hashes. No package can select a PNG path or crop.

A preset appearance is exactly `{presetId:'founder-v1'}`. Its illustration is selected as a whole; custom palette controls apply only to the separate manual modular appearance. Do not imply that preset clothing can currently be edited or that a stock fictional sprite represents an approved real resident.

`patch-v1` is an original fictional helper in the founder's art family: curly brown hair, glasses, orange jacket, cream tee and navy trousers. Its separate native atlas and20frame hashes follow the same crop, scale and pivot rules. Neither preset is a real resident portrayal. The existing manual modular creator remains available, with its own shared art definition and conformance fixtures; presets are selected whole.

No biography or personal introduction was provided.

The fixtures are separate examples; Founder/Patch remains the fictional default. Prompts and permission scope are recorded in [character prompts](../../../docs/design/community-character-prompts.json). The source remains an unchanged native image-generation output. Its reviewed row boundaries isolate touching sprites between the third/fourth rows; metadata crops stay within those cells. Back frames alternate the raised foot, and side frames alternate stride and raised-knee passing poses. This is a four-frame development animation, not a claim of a finished animation production pipeline.
