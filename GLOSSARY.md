# Shared vocabulary

- **Sample building**: fictional four-floor dataset; never a survey of a real site.
- **Floor**: a level with a stable ID, display name and elevation in meters.
- **Room**: a stable searchable destination with a footprint and routing entrance.
- **Checkpoint**: known building location identified by a validated QR payload.
- **Last seen**: latest accepted checkpoint observation and timestamp; not present location or live tracking.
- **Route**: graph path from last seen to a destination, with walking and connector segments.
- **Step-free**: routes that exclude stairs/inaccessible graph edges; sample data is not certified accessibility.
- **Grant**: permission for selected recipients to read the latest shared payload until server expiry or revocation.
- **Team simulation**: sample players contributing on the same device; no network session.
- **Discovery stop**: a hunt checkpoint with sample orientation content about an area and nearby fictional rooms or companies. It is not a verified campus directory.

- **Guide preview:** an optional pixel character animating a calculated sample route. It is independent of a person’s last-seen observation and never establishes location.

- **Room host (NPC / PNJ)**: a pixel character in a room introduction sheet. It explains fictional sample purpose and mission, and offers directions; it is not a real person, chatbot or positioning marker.
