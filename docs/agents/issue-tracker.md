# Issue tracker

The repository is `https://github.com/e-mric/BeThereCentral`. GitHub Issues is the intended public tracker; `docs/BACKLOG.md` remains the working roadmap and `docs/PRD.md` the product specification until work is explicitly moved into issues. Do not invent issue links or claim an unverified publication.

PRs as a request surface: no. Sending comments, issues or messages requires user authorization. Local implementation and documentation do not.
