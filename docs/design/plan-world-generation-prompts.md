# Furnished plan worlds — 8 October 2026

Generated with the built-in GPT image tool. Each floor used its own vector-derived 2048×768 stencil as the structural reference and the approved coworking concept as style reference. Stencils were created from source-pixel geometry; no supplied source bitmap was edited. Output PNGs are saved unchanged in the shared Compose drawable resources. The app clips them to independently traced exterior and courtyard geometry. Fictional interior walls, furniture and decorative characters are visual interpretation; they do not establish surveyed room entrances or routes. The generated alpha includes soft background shading; source clipping prevents it from filling the canonical courtyards.
