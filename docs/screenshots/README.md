# Screen evidence

`android-world-ground.png`, `android-world-first.png`, `android-world-second.png`, `android-world-third.png` and `android-world-fourth.png` show the five distinct furnished plan worlds in the dedicated Pixel 7 / API 36 emulator. `android-world-detail.png` shows a zoomed second-floor view after searching Campfire AI. These captures show actual app rendering, not image-generation mockups. They predate only a minor label adjustment that suppresses repeated full names and adds the fictional-interior notice in guide sheets; floor artwork and geometry are unchanged.

The interiors are fictional GPT artwork based on supplied plan proportions, clipped to source-derived outlines/courtyards. Names and approximate anchors come from the supplied directory. This does not verify measured dimensions, physical routes or phone performance.

Earlier captures record superseded sample interfaces, including the old rectangular map and the parked 3D engine room. See [verification status](../testing/STATUS.md) for each check's scope and limitations.
